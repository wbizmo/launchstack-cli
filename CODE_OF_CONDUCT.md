# Contributor Code of Conduct

All LaunchStack CLI participants are expected to communicate professionally and respectfully. Critique code and technical decisions, not personal characteristics. Harassment, threats, hate speech, intimidation, doxxing and repeated disruption are not acceptable.

This applies to GitHub issues, pull requests, related discussions and project collaboration. Report conduct concerns confidentially to williams@zivoralabs.xyz with the subject "LaunchStack contributor conduct". The maintainer will review available evidence confidentially as appropriate, seek further context when needed, and may moderate comments or restrict participation. This is a living governance policy, not a claim of completed third-party OpenSSF assessment.

For security vulnerabilities, use the separate [security reporting process](SECURITY.md).
