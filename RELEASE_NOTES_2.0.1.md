# LaunchStack CLI v2.0.1

Release date: 2026-07-11

This documentation and release-polish update followed the v2.0.0 launch. It introduced no runtime or API changes, and projects generated with v2.0.0 remained compatible.

## Improvements

- Redesigned the README and improved installation, Quick Start, command and project overview documentation.
- Added generated-project quality commands and improved production workflow and developer documentation.
- Improved the project's GitHub and npm presentation.

## Upgrade

```bash
npm install --global launchstack-cli@2.0.1
```
