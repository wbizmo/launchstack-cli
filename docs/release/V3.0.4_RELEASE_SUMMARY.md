## Release verification

Post-merge checks passed on Node 24.22.3 with PostgreSQL 16 and Node 26.13.1 with PostgreSQL 17: 42 root test files / 179 tests and 9 generated-project test files / 28 tests on each runtime. The bounded security corpus passed on both runtimes. Production dependency audits reported no high-severity vulnerabilities, the 23-component SBOM validated, and the generated production Docker image passed health and PostgreSQL readiness checks.

Benchmark measurements were collected on one host. The [benchmark reports](../benchmarks/README.md) include methodology, raw results and reproduction commands.

## Compatibility and known limits

- Node.js 20 is no longer supported. This runtime support change is breaking despite the 3.0.4 patch version.
- The generated API remains on Prisma 6. Prisma 7 migration is deferred until the datasource and client changes are separately tested.
- Managed file operations reject static symlink traversal and serialize LaunchStack writers.
- Generated API rate limiting uses an in-memory per-process store by default. Multi-replica deployments need a shared Fastify rate-limit store.
- Redis, queue and cron are complete local integrations. OAuth, storage, observability, WebSocket, email and webhook capabilities provide helper code only.
