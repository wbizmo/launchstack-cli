# LaunchStack CLI v3.0.6 engineering summary

v3.0.6 addresses findings from a published-package end-to-end review and adds clearer runtime and Docker build guidance.

| Area              | Change                                                                                                                                                       | Verification                                                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| Project mutations | Capability plans are refreshed under the project lock before applying, preserving concurrent independent installs.                                           | Stale-plan regression and simultaneous CLI `add queue` / `add cron` preserve manifest, state and generated files. |
| Production audit  | Inherited base Compose settings satisfy production CORS and JWT requirements; non-Git directories are identified separately from incomplete Git enumeration. | Focused audit regression tests and generated-project audit.                                                       |
| Runtime           | Unsupported CLI commands receive an actionable Node.js compatibility message; help and version remain usable.                                                | Runtime policy unit tests and Node 20/24/26 command checks.                                                       |
| Docker            | Added instructions to supply a custom CA using the Dockerfile's BuildKit secret mount.                                                                       | Generated production image health/readiness check with the BuildKit secret override.                              |

The local release gate passed on Node.js 24.22.1 with PostgreSQL 16: 43 root test files / 193 tests, 1,290 security cases, production dependency audit, SBOM, package smoke and generated API checks (9 files / 28 tests). The generated production Docker image passed health and readiness checks. Runtime smoke covered Node.js 20.20.2, 24.22.3 and 26.13.1. Measured capability mutation and transaction results are summarized in the [benchmark index](../benchmarks/README.md) and detailed in the corresponding reports.

See [release notes](../../RELEASE_NOTES_3.0.6.md) for the final local gate results and [benchmark documentation](../benchmarks/README.md) for measured performance data.
