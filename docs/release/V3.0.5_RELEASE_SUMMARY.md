# LaunchStack CLI v3.0.5 engineering summary

v3.0.5 is a maintenance release for project lock portability, manifest validation and project creation behavior.

| Area                 | Change                                                                                                                                                                                                                                                                 | Verification                                                                           |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Mutation reliability | Replaces hard-link locks with directory locks, retaining owner identity checks, stale lock recovery and cross-process serialization. Incomplete initialization is never reclaimed by age alone and may require manual cleanup after confirming no mutation is running. | Lifecycle tests cover live and stale owners, a paused acquirer and concurrent writers. |
| Project validation   | Supports v3 manifests and legacy configuration files.                                                                                                                                                                                                                  | Command tests cover both formats.                                                      |
| Project creation     | `--directory` names a parent directory; `--verbose` reports generation stages.                                                                                                                                                                                         | Destination resolution and command option tests.                                       |
| Runtime policy       | Accepts Node.js 24.22.0+ and 26.13.0+ in their respective major lines.                                                                                                                                                                                                 | CI and Docker remain configured for current patched Node.js versions.                  |
| Capability scope     | Keeps complete local integrations distinct from helper-only capability code.                                                                                                                                                                                           | README and capability guide describe the current coverage.                             |

The full local release gate passed on Node.js 24.22.1 and Node.js 26.13.1, each with PostgreSQL 17. Both runs included 43 root test files / 186 tests, 1,290 security cases, generated API checks (9 files / 28 tests), production dependency audit, SBOM validation and package smoke. The generated production Docker image also passed health and PostgreSQL readiness checks. The measured transaction sample is documented in [the transaction benchmark report](../benchmarks/transactions.md).

See [release notes](../../RELEASE_NOTES_3.0.5.md) for the complete verification details.
