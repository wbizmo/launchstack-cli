# Security Policy

## Supported releases

The currently supported LaunchStack CLI release is v3.0.7. Earlier versions are superseded for active security maintenance.

## Reporting a vulnerability

Please **do not post exploit details or secrets in a public GitHub issue**. Use the repository's GitHub **Security → Report a vulnerability** private reporting feature when it is enabled. If that feature is unavailable, email **williams@zivoralabs.xyz** with “LaunchStack CLI security report” in the subject, requesting a confidential channel and including the affected version and impact. Delivery to this mailbox was externally verified on 18 November 2026 and monitoring is part of the programme record.

Supply a minimal non-sensitive reproduction, version, affected command or generated-template feature, security impact and suggested remediation. Do not include live credentials.

Maintainers will triage privately, evaluate the affected release and its shipped dependencies/templates, record decisions, coordinate remediation and user communications when warranted, and credit reporters as agreed. **No fixed response SLA or guaranteed response time is claimed until an operational response team has adopted and evidenced one.**

For open-source license/compliance questions, use **williams@zivoralabs.xyz** with “LaunchStack license compliance” in the subject.
